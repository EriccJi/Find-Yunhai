# 寻找云海学姐（Find-Yunhai）

> 一款以校园为背景的迷宫冒险小游戏：在错综复杂的迷宫里寻找「云海学姐」，沿途收集原石、躲避教官的追捕，从出口进入下一关。

## 🎮 游戏简介

《寻找云海学姐》是一个迷宫系统。玩家需要在迷宫中移动、收集散落各处的 **原石**，集齐后从 **出口** 进入下一关；过程中要时刻警惕 **教官** 的追逐——一旦被教官抓到，本关即告失败。

## 🕹 游戏玩法

- **移动探索**：在迷宫中自由行走，摸索通往出口的路径。
- **收集原石**：迷宫里分布着若干原石，全部收集齐才能解锁出口。
- **躲避教官**：教官会在迷宫中追逐玩家，被抓到则本关失败。
- **通关进阶**：集齐原石后从出口进入下一关，继续寻找云海学姐。

## 🚀 运行方式

本仓库提供的是 **Windows x64 发行版**，无需安装，直接运行：

1. 下载 `迷宫.exe` 与 `bgm.wav`，并放在 **同一文件夹** 下（背景音乐需伴随 exe 才能播放）。
2. 双击 `迷宫.exe` 即可开始游戏。
